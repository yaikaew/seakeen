# Only Boo

### Storyline <a href="#h.y9dzuggvtyd7_l" id="h.y9dzuggvtyd7_l"></a>

"หมู" เด็กหนุ่มม.ปลาย ผู้มีความฝันที่อยากจะเดบิวต์เป็นศิลปินบอยแบนด์ ถูกย้ายโรงเรียน ชะตาทำให้หมูได้มาเจอ “แกง" คนขายข้าวแกง ความใจดีของแกงทำให้หมูประทับใจจนค่อย ๆ กลายเป็นความชอบ แล้วคนสายลุยอย่างหมู ชอบก็ต้องจีบสิครับ

หมูเพียรจีบแกง บวกไปกับการฝึกฝนการร้องการเต้นอยู่ตลอด จนได้เดบิวต์เป็นศิลปิน แต่การจะได้เป็นศิลปินนั้น กลับต้องแลกมาด้วยกฎเหล็กของค่าย คือ “ห้ามมีแฟนเด็ดขาด!!!!"

สุดท้ายเรื่องราวความรักของทั้งคู่จะลงเอยอย่างไร ติดตามได้ใน แค่ที่แกง Only Boo! ทุกวันอาทิตย์ เวลา 20:30 น. ทางช่อง GMM25 และรับชมพร้อมกันทาง Youtube : GMMTV OFFICIAL เริ่ม 31 มีนาคมนี้

กำกับซีรีส์ สกล วงษ์สินธุ์วิเสส
